# OCR quality vs. render DPI (synthetic A4 page)

Page: 20 mm margins, title + 3 paragraphs (Liberation Serif 11 pt) + 7x4 bordered table (Liberation Sans 10.5 pt).
Generated by `make_pages.py` (text re-rasterised at each DPI, identical layout), parsed with
`paddleocr-sharp parse` at defaults (layout + VL-1.6), scored by `score.py` against `truth.json`.
Text CER = Levenshtein over title+paragraphs (table removed); table = cell-exact match + CER of flattened cells.
Single page, single run per DPI, greedy decoding (deterministic); wall time is whole process on 4 cores incl. load.
